# 第三幕：最后一班车

来源为用户提供的 `station_runner.html`。保留双赛道横向跑酷、体力、碰撞回退、绕行与捷径、短跳/长跳、下蹲/快落和离站演出。独立页面在 `public/minigames/station-runner/index.html`，宿主适配器在 `src/minigames/station-runner/index.js`。

## 两种周目

- 一周目：44 秒，无途中道具；无论是否到达站台，都以错过列车收束，回到原剧本 `p1_07`。
- 非一周目：56 秒，提前出发；可拾取并使用护盾、体力、延时道具。抵达且没有超时则赶上列车，进入原剧本 `p2_07`。失败可以重试，或按用户要求直接继续。
- 失败后继续使用新增的短过场 `p2_station_missed`，表现错过这一班后选择下一班车，避免出现按时到站的对白；随后与成功分支在 `p2_08` 汇合，保留其余正式剧本。此过场是为小游戏失败结果补写的衔接，不属于原剧本。
- `youthOutcome` / `stationOutcome` 保存 `met` 或 `missed`。剧情树只显示走过的结果分支；恢复节点会同时恢复当时的结果。

## 操作、显示与音效

电脑：A/← 上道，D/→ 下道；空格/↑/W 跳跃，轻点短跳、按住长跳；↓/S 下蹲或快落。E 护盾、R 体力、Q 延时；P 暂停。空格确认开始、恢复、结算页主按钮。

手机：下方大按钮换道、跳跃、下蹲和使用道具；点按场地短跳，左右滑动换道、下滑下蹲。长跳通过按住跳跃按钮。两条赛道上移，底部留出触控空间；帮助说明可以展开，避免遮满屏幕。

主程序在 1280×720 坐标空间进行一次统一缩放，嵌入页面不重复缩放。进入玩法前需确认开始；打开宿主设置或隐藏页面时冻结倒计时。宿主音量控制游戏内低音量合成反馈，暂停与确认按钮使用统一菜单音效。

## 存档与旧版本

宿主 `minigameSaves['stationRunner:1|2']` 分别保存完整赛道、障碍状态、路程、计时、体力、道具、跳跃、换道和结算结果；约每 0.5 秒及重要操作时更新。恢复进行中的游戏先进入暂停状态，确认后再计时；恢复结算不会重复完成章节。

内容版本为 `station-runner-v4`。旧《出门之前》或《不要出声》小游戏存档回到青年剧情入口，不混用新玩法数据。上一版纯剧情的对白游标保留，已经进入按时上车剧本的节点标记为成功分支；未玩过本跑酷的节点不会凭空解锁。

`tests/station-runner.test.js` 用提供游戏的真实脚本验证两周目时间与结果、暂停、完整恢复、重复完成保护、损坏存档和剧情树分支权限。
